# Imitation de Jésus-Christ — Version Typst

Ce projet propose une mise en forme en **Typst** du texte classique *L’Imitation de Jésus-Christ*.

## ✨ Objectif

L’objectif est de fournir :
- une version proprement structurée en Typst
- une base facilement modifiable pour produire des PDF
- une ressource libre pour étude, lecture ou édition

## 📦 Contenu

- Source Typst du texte
- Organisation en chapitres/livres
- Configuration de mise en page

## 🚀 Utilisation

1. Installer Typst : https://typst.app
2. Compiler le projet :

```bash
typst compile main.typ
```

3. Le PDF généré apparaîtra dans le dossier courant.

## 📚 À propos du texte

L’Imitation de Jésus-Christ est une œuvre spirituelle chrétienne classique, traditionnellement attribuée à Thomas a Kempis (XVe siècle).
Le texte original est dans le domaine public.
